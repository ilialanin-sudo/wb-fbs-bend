# Дашборд FBS · два кабинета одного бренда

Каждый час GitHub Actions забирает свежие заказы из API Wildberries по обоим
кабинетам, пересчитывает юнит-экономику и публикует страницу на GitHub Pages.

**В отчёт попадает только FBS** — строки `warehouseType = «Склад продавца»`.
Модель FBW отброшена целиком и появляется единственный раз, как знаменатель
в показателе «доля FBS в кабинете».

---

## Настройка — один раз, минут десять

### 1. Репозиторий

Новый репозиторий на GitHub, **публичный** (бесплатный GitHub Pages работает
только с публичными). Залейте туда содержимое этой папки.

Секретного в файлах нет: токены и себестоимость живут в секретах,
`cost.json` и `data/` — в `.gitignore`.

### 2. Pages

`Settings → Pages → Build and deployment → Source: **GitHub Actions**`

### 3. Секреты

`Settings → Secrets and variables → Actions → New repository secret`

| Секрет | Что класть |
| :-- | :-- |
| `WB_TOKEN_OOO` | Персональный токен кабинета ООО |
| `WB_TOKEN_IP` | Персональный токен кабинета ИП |
| `COST_JSON` | Содержимое `cost.json` целиком (формат — в `cost.example.json`) |
| `TELEGRAM_BOT_TOKEN` | Токен бота, если нужна сводка в Telegram. Без него шаг просто пропускается |
| `TELEGRAM_CHAT_ID` | Куда слать сводку: ваш id или id группы |

Токен WB обязательно **Персональный**, с категориями **Статистика, Финансы,
Продвижение**. Базовый не потянет: `/supplier/orders` после пары обращений
отдаёт 429 с требованием ждать больше часа. Права только на чтение —
записи скрипт не делает. Живёт токен 180 дней.

### 4. Переменные

Та же страница, вкладка **Variables**:

| Переменная | Значение |
| :-- | :-- |
| `DASHBOARD_URL` | Адрес страницы: `https://<логин>.github.io/<репозиторий>/`. Попадёт кнопкой в сообщение |
| `NOTIFY_PERIOD` | За какой период слать сводку: `yday` (по умолчанию), `week`, `d14`, `d28` |

`DASHBOARD_URL` заполните после первого деплоя — точный адрес покажет вкладка Actions.

### 5. Запустить руками

`Actions → FBS dashboard → Run workflow`, галочка «Пересобрать финотчёт».
Первый прогон 15–25 минут: финотчёт жёстко лимитирован, между запросами
выдерживаются паузы. Дальше каждый час по 2–3 минуты.

Адрес страницы появится во вкладке Actions после первого деплоя.

## Как делиться

После первого деплоя страница живёт по адресу
`https://<логин>.github.io/<репозиторий>/` и обновляется каждый час.
Ссылку можно кидать в чат, открывать с телефона, показывать на встрече —
ничего устанавливать не нужно. Кнопка **⇪** в шапке отдаёт ссылку в системное
«Поделиться» или кладёт в буфер обмена.

Страница помечена `noindex` — в поиск не попадёт, но **пароля на ней нет**:
кто знает адрес, тот видит цифры. Если понадобится закрыть — скажите, добавлю
шифрование данных прямо в HTML (ключ из пароля, страница спрашивает его при
открытии).

**Сводка в Telegram** уходит раз в сутки в 10:17 МСК: заказы, выкуп, разложение
маржи и кнопка на дашборд. Прислать вне расписания — `Actions → Run workflow`,
галочка «Прислать сводку в Telegram».

## Как это устроено

| Файл | Зачем |
| :-- | :-- |
| `wb_client.py` | HTTP к WB: `Authorization` без `Bearer`, честная отработка 429 |
| `collect.py` | Выгрузка: заказы, продажи, реклама — каждый час; финотчёт — раз в 20 часов |
| `aggregate.py` | Периоды, когорты, юнит-экономика → `dashboard_data.json` |
| `render.py` | Данные + вёрстка → `dist/index.html` |
| `notify.py` | Сводка и ссылка в Telegram |
| `template.html` | Сам дашборд |
| `config.json` | Настройки и ручные переопределения ставок |
| `state/rates.json` | Ставки из финотчёта. Коммитится в репозиторий и живёт между запусками |

Ежечасный прогон делает 6 запросов к WB и не трогает финотчёт — иначе не
уложиться в лимиты. Ставки экономики берутся из `state/rates.json`, который
обновляется раз в сутки.

## Главное про цифры

**База — сырой заказ.** У WB флаг `isCancel` ставится и на отмену клиентом,
и на невыкуп, и приходит с задержкой в неделю-полторы. У сегодняшнего дня
отмен около 2 %, у дозревшей когорты — 55–60 %. Поэтому считать экономику от
«живых» заказов нельзя: свежий день был бы завышен вдвое. Все расчёты идут от
полного числа заказов, а доля дошедших до выкупа задаётся отдельной ставкой.

**Экономика считается от цены продавца до скидки маркетплейса**
(`priceWithDisc`), а не от того, что заплатил покупатель. СПП внутри строки
«комиссия WB, эквайринг и СПП» и показана отдельной справочной ставкой.

**Ставки — факт, а не тариф.** Финотчёт сшивается с заказами по `srid`: для
когорты заказов, которую отчёт уже закрыл, суммируются реальные списания и
делятся на число сырых заказов когорты.

**Логистика берётся на каждый сырой заказ,** а не на выкуп: WB платят и за
доставку до покупателя, и за обратный путь невыкупа — около 1,5 события на заказ.

**Реклама — единственная оценочная строка.** Большинство карточек продаётся
одновременно по FBS и FBW одной кампанией, поэтому чисто FBS-расхода в API не
существует. Он разносится по доле FBS в заказах той же карточки.

**Себестоимость** применяется только к выкупленным единицам: возврат
возвращается в сток. Артикулам без себестоимости подставляется средняя по
покрытым, процент покрытия виден на странице.

## Обслуживание

**Поменялась себестоимость.** Обновите секрет `COST_JSON`. Достаточно любого
из двух словарей — `by_article` или `by_nmid`.

**Хотите задать выкуп или ставки руками.** `config.json`, блок `override`:

```json
"override": { "ooo": { "buyout": 0.34, "logistics_per_order": 175 } }
```

Заполненное поле побеждает расчёт из финотчёта, и на странице так и будет
написано — «задан вручную».

**Не хотите прокси по кабинету.** `"rates_fallback": "none"` — пока когорты
FBS не дозреют, блок экономики покажет «данных мало» вместо оценки.

**Токен протух.** Живёт 180 дней. Сборка упадёт — выпустите новый и обновите
секрет.

**Сменить время сводки.** Шаг «Сводка в Telegram» в workflow сравнивает час UTC
с `07`. Поменяйте на нужный: МСК минус три.

**Сменить частоту.** Строка `cron: "17 * * * *"` в
`.github/workflows/dashboard.yml`. GitHub может задержать запуск на 5–30 минут
при высокой нагрузке — это его штатное поведение, не поломка.

**Расход Actions.** Около 3 минут в час плюс 20 минут в сутки на финотчёт —
примерно 100 часов в месяц. На публичном репозитории бесплатно.
